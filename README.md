A visually polished and responsive static landing page developed as part of my Web Development Internship. The project demonstrates fundamental front-end development skills using HTML5 and CSS3.

This project is a modern landing page designed for a product, service, or brand. It focuses on clean UI design, responsive layout, navigation, and user-friendly presentation.
